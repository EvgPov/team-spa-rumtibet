# RumTibet — Поиск и бронирование туров

**Командный учебный проект** — Single Page Application для поиска и бронирования туристических поездок.

**Моя роль:** Backend-разработчик (полная реализация серверной части)

## О проекте

RumTibet — веб-приложение, которое помогает пользователям находить подходящие туры, изучать подробные программы поездок, сравнивать цены и бронировать путешествия.

## Мой вклад (Backend)

Я полностью разработала backend-часть проекта:

- Реализовала REST API на базе json-server
- Создавала и наполняла базу данных (`db.json`)
- Разработала все эндпоинты (`/data` и `/blogs`)
- Реализовала полный набор CRUD-операций
- Написала утилитарные функции для работы с API (`api.js`, `script.js`, `constants.js`)
- Подготовила подробную документацию API (`docs/api.md`)
- Обеспечила стабильное взаимодействие frontend и backend

## Стек технологий (Backend)

- Node.js
- json-server
- JavaScript (ES6+)
- REST API
- Axios
