# RumTibet — Поиск и бронирование туров

**Командный учебный проект** — Single Page Application для поиска и бронирования туристических поездок.

**Моя роль:** Backend-разработчик

### О проекте
RumTibet — веб-приложение, которое помогает пользователям искать туры, изучать программы поездок, сравнивать цены и бронировать путешествия. Проект создан в рамках командной разработки.

### Мой вклад (Backend)
Я полностью разработала backend-часть проекта:

- Реализовала REST API с использованием json-server
- Настроила и заполнила базу данных (`db.json`)
- Разработала все эндпоинты для работы с данными:
  - `/data` — информация о локациях, турах, программах и услугах
  - `/blogs` — отзывы путешественников
- Реализовала CRUD-операции (получение, добавление, обновление и удаление данных)
- Написала утилитарные функции для работы с API (`api.js`, `script.js`)
- Подготовила подробную документацию API (`docs/api.md`)
- Обеспечила корректную работу сервера совместно с frontend-частью

### Стек технологий (Backend)
- Node.js
- json-server
- JavaScript (ES6+)
- REST API
- npm-run-all, wait-on
